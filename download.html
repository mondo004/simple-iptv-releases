Installing with a computer instead

A plain install leaves the app interpreted and slow to start on weak TV hardware. If you have adb, install the profile alongside it:

adb install-multiple -r stable.apk stable.dm

Use stable-api28.dm instead on Android 9–11, which is every Fire TV stick; rename it to stable.dm first, since adb pairs the two by filename. Downloader installs a single file and cannot carry either one.
